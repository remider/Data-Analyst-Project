📌 Столбцы и их значения:
id  | Число | Уникальный ID товара (например, 1001, 1002).
product_name   | Текст |  Название смартфона и модель (например, iPhone 15 Pro, Samsung Galaxy S23).
category	| Текст |  Категория: Flagship (флагман), Mid-Range (средний класс), Budget (бюджет).
sold	| Число | Количество проданных единиц за период.
price  |Число ($) |  Цена продажи для клиента.
margin | Число ($)  |  Прибыль с одной единицы: price - cost.


📊 ABC-анализ по 3 параметрам
1. По цене (price)
Логика:
A (80% товаров): Цена ≥ 20-го перцентиля
B (15% товаров): Цена между 5-м и 20-м перцентилем
C (5% товаров): Цена < 5-го перцентиля (самые дешевые)

2. По продажам (sold)
Логика:
A (80%): Хиты продаж 
B (15%): Средний спрос
C (5%): Неликвид

3. По марже (margin)
Логика:
A (80%): Товары с высокой рентабельностью
B (15%): Средняя маржа
C (5%): Убыточные позиции
